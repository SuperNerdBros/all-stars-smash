## 1. The Object of the Game

There are no health bars here. Every hit raises your **damage %**, and the higher it climbs, the **farther you fly** when you get hit. Knock your opponents past the edges of the screen, the **blast zones**, to take a **stock**.

Lose all your stocks and you're out. **The last fighter standing wins.**

```
   ┌────────────────────── BLAST ZONE ──────────────────────┐
   │                                                        │
   │        ▓▓▓                              ▓▓▓            │
   │      ══════         ★ 0% ★          ══════             │
   │                                                        │
   │   ════════════════════════════════════════════         │
   │                                                        │
   └────────────────────────────────────────────────────────┘
          fly past the line  →  lose a stock
```

## 3. Your Moveset: Stick + Button

Every fighter has the **same 23-move layout**, so once you learn one, you can pick up any of them. **Where you point the stick when you press the button decides the move.**

### On the ground: Attack button

| Input | Move | What it's for |
|---|---|---|
| **A** (stick neutral) | **Jab** | Fastest move you have. Interrupt pressure. |
| **Hold → + A** | **Forward tilt** | Spacing poke. Keeps them out. |
| **Hold ↑ + A** | **Up tilt** | Anti-air, juggle starter. |
| **Hold ↓ + A** | **Down tilt** | Low, fast, trips them into combos. |
| **Running + A** | **Dash attack** | Lunging punish across the stage. |
| **Flick → + A** | **Forward smash** ⚡ | Your big KO move. |
| **Flick ↑ + A** | **Up smash** ⚡ | Launches straight up. Punishes landings. |
| **Flick ↓ + A** | **Down smash** ⚡ | Hits **both sides**. Rolls get punished. |

**Flick vs. hold:** if you press the direction **within 3 frames** of the button, it's a flick and you get a **smash** attack. If you were already holding the direction, you get a **tilt**. The **Smash button** and the **C-stick** always give a smash.

⚡ **Hold the button to charge a smash** for up to one second. A full charge does **1.4× damage**, and your fighter flashes while charging.

### In the air: Attack button

| Input | Move |
|---|---|
| **A** | **Neutral air**: hits all around you. Your "get off me" button. |
| **→ (toward facing) + A** | **Forward air**: your best edge-guard. |
| **← (behind you) + A** | **Back air**: stronger than forward air. Turn your back to the stage and hit them off it. |
| **↑ + A** | **Up air**: juggle them from below. |
| **↓ + A** | **Down air** ☄️: the sweet spot at your feet **meteors**, spiking them straight down. |

Aerials don't turn you around. Hit the ground mid-move and you take **landing lag**, so space them so they end before you land.

### Specials: B button (works in the air too)

| Input | Move | Typical role |
|---|---|---|
| **B** | **Neutral special** | Projectile or signature move |
| **→ / ← + B** | **Side special** | Lunge, turns you around |
| **↑ + B** | **Up special** | **Recovery**: get back to the stage. Once per airtime. |
| **↓ + B** | **Down special** | Multi-hit spin, pressure tool |

### Grabs & throws

**Grab** with the grab button, or **Shield + A**. Grabs go right through shields.

| While holding | |
|---|---|
| **A** | **Pummel**: extra damage before you throw |
| **→** | **Forward throw** |
| **←** | **Back throw** (you turn around; usually the strongest) |
| **↑** | **Up throw**: sets up juggles |
| **↓** | **Down throw**: weight-independent, the most reliable combo starter |

Being held? **Mash any button** to break free faster. The more damage you have, the longer they can hold you.

## 4. Advanced Techniques

| Technique | How | Why |
|---|---|---|
| **Short hop** | Tap jump and release before liftoff (3 frames) | A low jump for fast aerials that land before the opponent can react |
| **Fast fall** | Hold **↓** while falling | Land sooner, get back to the ground, take less landing lag |
| **Wall jump** | Jump while touching a wall | Recovery and mix-ups |
| **Up-smash / Up-B out of jump** | Press ↑+A or ↑+B during jump startup | Hit them from your shield the moment their attack ends |
| **Platform drop** | Hold **↓** on a thin platform | Drops through. Press A in the first 2 frames for a down-tilt instead |
| **Crouch** | Hold **↓** on the ground | **Crouch cancel**: you take **0.67×** knockback and hitstun |
| **Charge cancel** | Let go of a charging smash early | Throws off their timing |

## 5. Getting Hit (and Living)

This game uses the knockback and hitstun math from classic platform fighters. Here's what's happening and what you can do about it.

### 💥 Hitstop: the freeze on impact
When a hit lands, **both fighters freeze** for a moment. Bigger hits freeze longer, electric hits freeze **1.5×** longer, and a clean sweet spot freezes longer than a sour one. **Those frozen frames are your window to act.**

### 🕹️ DI: Directional Influence
On the **last frame of the freeze**, the direction you're holding **bends your launch angle** by up to 18°. Holding at a right angle to the launch bends it the most.
- **Survival DI:** hold toward the **upper corner** away from the closest blast zone. You'll live several % longer.
- **Combo DI:** hold **away** from your opponent so their follow-up misses.

### 🌀 SDI: Smash DI
**Tap** directions *during* the freeze. Each tap **nudges you** a little, which is enough to slip out of multi-hit moves before the last hit.

### 🎈 Balloon knockback
Launches start **fast** and slow down quickly. You end up just as far away, but the match keeps moving.

### 🔁 Stale moves
The game remembers your **last 9 hits**. Use the same move over and over and it gets **weaker**, losing about 9% per recent use. A move you **haven't used yet** gets a **1.05× bonus**. Hits on shields count too. Your record clears when you lose a stock.

> Mix it up. A fresh smash attack can KO when a stale one won't.

### ⚖️ What changes knockback
- **Weight:** heavy fighters are harder to launch.
- **Rage:** at high damage, *your* hits get up to **10%** stronger. Comebacks are real.
- **Gravity:** floaty fighters drift up and away, and heavy fallers drop back down quickly.

## 6. Game Modes

| Mode | |
|---|---|
| **⚡ Quick Brawl** | Random fighters, random stage, straight into the fight |
| **🥊 Versus** | Pick fighters, colors, stage and stocks. Local 2P or vs. CPU |
| **👥 2–8 Fighter Free-for-All** | Fill the room with up to 8 fighters. Each empty seat gets a CPU (Lv. 3 / 6 / 9) |
| **🌐 Online Rooms** *(coming soon)* | Host a room with CPUs, share the code, and friends **take over CPU seats** as they join. Rollback netcode keeps it smooth across the country |

### 🌐 About online play
- **Rollback netcode.** Your inputs register instantly. If a friend's input arrives late, the game rewinds a few frames and replays them correctly. Matches stay in sync with up to **8 players**.
- **It costs nothing to run.** The host's browser runs the match and players connect directly over WebRTC. Each player sends **less than 1 KB/s**.
- **Room codes** use 5 letters with no vowels and no look-alike characters, so they're easy to read out loud.

## 7. The Pixel Forge

Press **PIXEL FORGE** on the title screen to open the sprite editor.
- Paint fighters frame by frame on an indexed 16-color palette.
- Import a PNG sprite sheet. The **#FF00FF** magenta key color becomes transparent.
- Hot-reload a fighter into a live match to see your changes immediately.
- Custom fighters are saved in your browser.

## 8. Hints & Tips

- 🛡️ **Shields wear down.** Hold one too long and it **breaks**, leaving you stunned. Let go and it slowly regenerates.
- ☄️ **A meteor near the ledge is the fastest KO** in the game. Down air an opponent who's trying to recover.
- 🔙 **Back air is stronger than forward air.** Practice turning around in the air.
- 🎯 **Down throw first.** It's weight-independent, so it combos the same way on every fighter.
- 🧊 Watch the floor: **ice** is slippery, **springs** launch you up, and **conveyors** carry you along.
- 📸 Press **H** to see hitboxes. Red boxes hit, green boxes can be hit. This is the best way to learn spacing.

## 9. For Developers

```bash
pnpm install          # or npm install
pnpm dev              # http://localhost:3000
npm test              # engine, netcode and determinism tests
STATIC_EXPORT=1 npx next build   # static site in out/ (what GitHub Pages serves)
```

### How it's built

| Layer | Where | What it does |
|---|---|---|
| **Engine** | `lib/engine/` | Deterministic 60 Hz simulation in a Web Worker with an OffscreenCanvas 2.5D sprite-stack renderer |
| **Combat math** | `lib/engine/combatFormulas.ts` | Knockback, hitstop, DI, staling and charge, all tunable in `ENGINE_TUNING` |
| **Input → move** | `lib/engine/moveResolver.ts` | Turns stick + button input into one of the 23 moves |
| **Movesets** | `lib/roster/movesetBuilder.ts` | Builds all 23 moves from 5 core moves; override any of them per fighter |
| **Netcode** | `lib/net/` | Rollback session, state snapshots and checksums |
| **Online API** | `play-api/` | Cloudflare Worker with Lobby and Room Durable Objects: room codes, quick join, WebRTC signaling, TURN |

### Authoring a fighter's moves

Each fighter writes **5 core moves**, and the other 18 are built from them. To change any move, override only the fields you need:

```ts
export const MY_FIGHTER: FighterBlueprint = {
  // …stats, sprites…
  moveset: { jab, smash, aerial, neutralSpecial, upSpecial }, // required
  moves: {
    dair: { damage: 14, launchAngleDeg: -80 },      // stronger meteor
    utilt: { hitbox: { width: 28 } },               // wider up tilt
    fsmash: {
      hitboxes: [                                   // sweet spot first: lowest id wins
        { id: 0, offsetX: 22, offsetY: -12, width: 10, height: 10, hitlagMult: 1.25 },
        { id: 1, offsetX: 10, offsetY: -12, width: 14, height: 12, damage: 9, hitlagMult: 0.7 },
      ],
    },
  },
};
```

`npm test` checks every fighter's frame data, so broken moves fail the build before they ship.
